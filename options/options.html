Getting started

  1. Add an API key above (Anthropic, OpenAI, Gemini or OpenRouter) and press Test & load models.
  2. Create a character with a precise, fixed appearance.
  3. Pin ScenePull: click the puzzle icon in Chrome's toolbar → pin. Click it on any TikTok or Instagram video to open the side panel. Drag the panel's edge to make it wider.
  4. Follow the 5 tabs: Capture → Character → Brief → Produce → Publish. ⚡ cards are automated; ✋ cards are the steps you do yourself.
  5. Shortcut: Alt+Shift+S opens the panel.

ScenePull only reads what's publicly visible on the page you're viewing. It never reads your login, messages or private data. Please follow each platform's rules, label AI-generated content, and only create original characters — never imitate real people.
